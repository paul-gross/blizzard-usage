# Using Blizzard

| Topic                                | When to read                                                                              |
| ------------------------------------ | ----------------------------------------------------------------------------------------- |
| [overview.md](./overview.md)         | You are new to Blizzard or need to identify your session's role.                          |
| [connection.md](./connection.md)     | Before your first fleet call, or when the target, access, or installed tools are unclear. |
| [work/](./work/index.md)             | You need to inspect, prepare, steer, or answer work.                                      |
| [delivery.md](./delivery.md)         | Work is landing, waiting to merge, or appears stuck in delivery.                          |
| [workers.md](./workers.md)           | You are a leased fleet worker carrying out an assigned node-step.                         |
| [runner-hosts.md](./runner-hosts.md) | You need to inspect runner availability or operate a runner host.                         |
